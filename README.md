#apple

A minimal, offline, daily mantra/inspiration app for Android.

##Features

- One quote a day at designated time of chosen category
- 5 categories with a 'Surprise me' mode
- No accounts, cloud services or internet connectivity needed.
- Private, on-device preferences and history stack

## Tech Stack

-Kotlin
-Jetpack Compose
-Android SDK
-DataStore
-Local notifications
